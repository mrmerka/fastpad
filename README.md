---

## Описание

**FastPad** — это легкий текстовый редактор для тех, кто хочет просто писать текст. Никакого лишнего интерфейса — только текст и горячие клавиши.

> Вдохновлён идеей "физического блокнота": открыл, записал, закрыл.

---

## Возможности

- ✅ **Мгновенный запуск** — никаких задержек
- ✅ **Встроенный шрифт JetBrains Mono** — работает без установки
- ✅ **Тёмная и светлая тема** (Ctrl+P)
- ✅ **Поиск по тексту** (Ctrl+F)
- ✅ **Ручное сохранение** — только когда нужно
- ✅ **Запоминает настройки** (шрифт, тема, последний файл)
- ✅ **Кроссплатформенный** — Windows, Linux, macOS

---

## Горячие клавиши

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+N` | Новый файл |
| `Ctrl+O` | Открыть файл |
| `Ctrl+S` | Сохранить |
| `Ctrl+Shift+S` | Сохранить как |
| `Ctrl+F` | Поиск |
| `Ctrl+P` | Настройки |
| `Ctrl+W` | Закрыть |
| `Ctrl+Q` | Выйти |
| `Escape` | Закрыть окно |

1. Скачай [последний релиз](https://github.com/твой-проект/FastPad/releases)
2. Распакуй архив
3. Запусти `FastPad.exe`/`FastPad`
